# 提交检查清单

截止时间：2026 年 9 月 2 日 24:00（北京时间）。截止后不要再向公开仓库推送新提交。

## 仓库

- [ ] 新建公开 GitHub 或 Gitee 仓库，并确认访问无需登录。
- [ ] 把真实仓库 URL 写入 `README.txt` 第一段，删除“待发布后填写”。
- [ ] 提交历史完整、时间和内容能反映开发过程；不要压缩或改写已推送历史。
- [ ] 仓库、README、视频及审计示例中均无 API key 或其他凭据。
- [ ] 最后运行 `python -m unittest discover -v` 并记录全绿结果。
- [ ] 构建并安装 wheel，确认在仓库外目录运行 `forge --version` 和 `forge`。
- [ ] 截止后不再 push。

## README.txt

- [ ] 总长度不超过 1000 个汉字。
- [ ] 包含仓库地址、运行方式、特色功能。
- [ ] 在一台没有项目缓存的新环境中照步骤运行一次。

## 视频

- [ ] MP4 格式，时长不超过 2 分钟，文件不超过 200 MB。
- [ ] 展示 Agent 完成一个真实编程任务，并简要讲解实现。
- [ ] 可剪辑、加速，但关键结果清晰可见。
- [ ] 未出现 API key、系统通知或个人隐私。

## 最终压缩包

- [ ] 只包含 `README.txt` 和视频文件。
- [ ] 压缩包命名为“你的姓名.zip”。
- [ ] 解压复查两个文件可正常打开。
- [ ] 上传到题目指定表单；若重复上传，确认最后一次为正确版本。
