# 两分钟演示视频脚本

## 演示前准备

1. 复制 `examples/demo_project` 到仓库外的临时目录，避免改动演示素材原件。
2. 终端字号调大，窗口只保留命令区和编辑器文件树。
3. 设置 `FORGE_API_KEY`、`FORGE_BASE_URL`、`FORGE_MODEL`，确认画面不出现密钥。
4. 先运行 `python -m unittest demo_tests.py -v`，确认两个测试失败。

推荐任务词：

> 阅读当前项目，修复库存计价函数：折扣应按百分比计算并保留两位小数，非法价格或折扣应抛出 ValueError。不要修改测试，完成后运行全部测试并总结改动。

## 分镜与讲稿

### 0:00-0:12 题目与定位

画面：仓库首页或文件树。

讲稿：“这是我从零实现的 CodingAgent。它没有使用任何 agent 框架，核心是自己编写的模型调用、tool calling 循环、本地文件工具、上下文管理和终止策略。”

### 0:12-0:27 架构亮点

画面：快速展示 `agent.py` 循环和 `tools` 目录。

讲稿：“模型只负责选择动作；所有读写和命令都由本地工具执行。工具失败也会作为 observation 回到对话，所以 agent 可以根据真实错误修正方案。”

### 0:27-0:40 展示失败基线

画面：在临时 demo 目录运行测试，显示失败。

讲稿：“这里有一个真实的小型计价模块。现有实现把折扣百分比直接当金额相减，也没有参数校验。”

### 0:40-1:28 运行 Agent

画面：执行：

```powershell
python D:\path\to\forge-agent\main.py -i -w D:\path\to\demo "阅读当前项目，修复库存计价函数：折扣应按百分比计算并保留两位小数，非法价格或折扣应抛出 ValueError。不要修改测试，完成后运行全部测试并总结改动。"
```

讲稿：“终端会流式显示模型内容和每轮工具调用。它先列目录并读取实现和测试，再做精确修改，最后运行测试。路径被限制在 workspace；命令默认不用 shell，并受允许列表和超时控制。”

操作提示：当终端出现 `[confirmation required]` 时输入 `a` 一次放行本次后续操作，或输入 `y` 只放行当前动作；若输入 `n`，工具不会执行，拒绝结果会回传给模型。也可以启动时加 `--yes`。

若模型运行较慢，可在等待段加速，但关键的读文件、改文件、测试通过三个节点保留正常速度。

### 1:28-1:47 检查结果

画面：测试全绿，打开修改后的 `inventory.py`。

讲稿：“修改后全部测试通过。Agent 的完成条件不是写完文件，而是模型看到测试结果后主动给出最终总结。”

### 1:47-2:00 可观测性与收尾

画面：在同一 `forge>` 会话追问“为什么这样修改”，随后展示 `.forge/runs` 的 JSONL 首尾和运行摘要。

讲稿：“完成后仍可连续追问，历史会保留；每个会话还有脱敏审计轨迹，记录模型轮次、工具结果、改动文件与退出原因。完整实现和测试均在公开仓库中。”

## 录制检查

- 时长不超过 2 分钟，导出 MP4，小于 200 MB。
- 画面中无 API key、环境变量值、通知弹窗或个人隐私。
- 至少清楚出现：失败基线、文件读取、代码修改、测试通过、最终总结。
- 可以剪辑和加速，但不要剪掉真实工具输出与测试结果。
